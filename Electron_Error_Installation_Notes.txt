1. Open your project's package.json.

2. Add the overrides block (or resolutions if you use Yarn) to the root level of the file:
		
		
		"overrides": {
  			"yauzl": "^3.3.1"
		}

3. Run the cleanup and installation sequence in your terminal:

		# Delete the existing, half-broken install
		rm -rf node_modules package-lock.json

		# Reinstall with the override in place
		npm install

During npm install, the override forces Electron's extraction pipeline to use yauzl v3.3.1. The underlying install.js will now cleanly extract the binaries and correctly generate your missing paths.txt file.
